# Nutripetia — Web

Repositorio de la web pública de Nutripetia: Jekyll + Just the Docs, contenido en español e inglés.

## Separación de responsabilidades
- **Web:** presentación, navegación, accesibilidad, SEO técnico y publicación autorizada.
- **Workteam:** dirección, tareas, briefings, auditorías, decisiones y logs.
- **Repositorio científico oficial:** Canon IA, cinco protocolos y expedientes científicos; referencia exacta pendiente de verificar.

No duplicar Canon ni expedientes científicos. Solo publicar resultados revisados y autorizados.

## Fases editoriales
1. Base web y metodología.
2. Investigaciones científicas revisadas.
3. Artículos divulgativos vinculados a investigaciones.
4. Guía futura `/guia/` sin páginas vacías ni `/atlas/` paralelo.

## Estado y pendientes
Esqueleto técnico-editorial creado; no implica que la web esté desplegada ni validada. Dominio, URL canónica, Search Console, datos legales, licencia, versión normativa científica y publicación están pendientes. No se ha ejecutado una compilación ni auditoría automatizada.

## Desarrollo
Jekyll con `github-pages` y tema remoto `just-the-docs/just-the-docs`. Antes de activar Pages: comprobar compilación, compatibilidad de plugins, enlaces, accesibilidad, SEO, seguridad y autorizaciones. Cambios sujetos a G0–G5 de Workteam.
